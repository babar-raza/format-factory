## 1. File Size and Complexity

- [ ] No `.py` or `.cs` source file under `src/` exceeds 800 LOC. `[V35]`
- [ ] Existing violations are in `registry/source-structure-baseline.json` and tracked by `baseline_loc_cap`. `[ADVISORY]`
- [ ] LOC must not regress past `baseline_loc_cap` for files already in `known_violations`. `[V35]`
- [ ] No Python source file under `src/python/` has more than 80 top-level function definitions. `[UNVALIDATED]` (V187 planned)
- [ ] Files with function count >80 that are in `known_violations` must not regress past `baseline_functions_cap`. `[UNVALIDATED]` (V187 planned)
- [ ] `__init__.py` is ≤100 LOC (re-exports and `__all__` only). `[DEFINED_ONLY]`
- [ ] `exceptions.py` is ≤100 LOC. `[DEFINED_ONLY]`
- [ ] `constants.py` is ≤200 LOC. `[DEFINED_ONLY]`
- [ ] `models.py` is ≤200 LOC. `[DEFINED_ONLY]`

## 2. Module Structure (Python)

- [ ] Every format package under `src/python/{format}/` has a `__init__.py`. `[V109]`
- [ ] Every format package has a parser file (`{format}_parser.py` or `parser.py`). `[DEFINED_ONLY]`
- [ ] Codec files (`{format}_codec.py`) handle at most 2 roles: load + write. No analytics in codec. `[V66][REAL_FILE_TESTED]`
- [ ] `__init__.py` declares explicit `__all__` using the dynamic pattern or an explicit list. `[V65]`
- [ ] Analytics functions live in `{format}_analytics.py`, not in codec/parser/model files. `[V66]`
- [ ] The `analytics/` sub-package is used when `{format}_analytics.py` exceeds 800 LOC. `[V35]`
- [ ] No `*_analytics_extra.py`, `*_misc.py`, `*_helpers.py`, `*_utils.py` in `src/python/`. `[V50][REAL_FILE_TESTED]`
- [ ] No `*_document.py` whose module docstring contains `"analytics functions"`. `[V69][REAL_FILE_TESTED]`
- [ ] Domain model classes live in `models.py`; no model classes in parser or codec. `[ADVISORY]`
- [ ] `spec/` directory holds only `architecture_only` stubs generated by the canonical stub generator. `[V48]`
- [ ] `Compat/` directory holds only facade classes (one file per spec QName entry). `[V52][ADVISORY]`
- [ ] No file exists in `src/python/` outside the approved layout contract. `[V109]`
- [ ] Files not matching recognized purpose (parser/model/analytics/writer/etc.) are flagged as orphans. `[V100]`

## 3. Module Structure (.NET)

- [ ] Each format has its own `.csproj` under `src/net/{format}/`. `[DEFINED_ONLY]`
- [ ] No `.cs` file under `src/net/` exceeds 800 LOC. `[V70]`
- [ ] `{Format}Document.cs` is ≤800 LOC. `[V70]`
- [ ] No `*Missing*.cs` or `*Stub*.cs` files added to `src/net/`. `[V89]`
- [ ] No `Dictionary<>` fields detached from XML parse path. `[ADVISORY]`
- [ ] No `public Get*()` method that returns a constant (not read from parsed data). `[V87][ADVISORY]`
- [ ] All source code lives in `src/net/` (NOT `src/dotnet/`). `[V110]`
- [ ] `{Format}Parser.cs` contains parse-only logic. `[DEFINED_ONLY]`
- [ ] `{Format}Writer.cs` contains write-only logic. `[DEFINED_ONLY]`

## 4. Layer Separation

- [ ] Each `.py` file occupies at most ONE layer (parser, model, analytics, writer, export, compat, api). `[V66][REAL_FILE_TESTED]`
- [ ] Parser files do NOT import from analytics. `[V75][ADVISORY]`
- [ ] Analytics files do NOT import from writer. `[V75][ADVISORY]`
- [ ] No circular imports between layers in the same format package. `[ADVISORY]`
- [ ] Analytics functions in `*_analytics.py` do not perform I/O at module level. `[UNVALIDATED]` (V189 planned)
- [ ] Domain model files (`models.py`, `*_document.py`) do NOT import `os`, `io`, or `pathlib`. `[UNVALIDATED]` (V188 planned)
- [ ] Analytics files do not access the filesystem at module scope (only inside functions). `[UNVALIDATED]` (V189 planned)
- [ ] `__init__.py` contains ONLY re-exports; no business logic. `[DEFINED_ONLY]`

## 5. Naming Conventions

- [ ] Analytics functions are prefixed `{format_id}_` (e.g., `csv_row_count`). `[ADVISORY]`
- [ ] Parse functions follow: `parse_{format}` / `parse_{format}_strict` / `probe_{format}`. `[DEFINED_ONLY]`
- [ ] No vague class or module names: `Utils`, `Helpers`, `Manager`, `Processor`, `Handler`. `[V117]`
- [ ] No catch-all file patterns: `_utils.py`, `_helpers.py`, `_misc.py`. `[V117]`
- [ ] Statistics file named `{format}_analytics.py` (singular). `[V50]`
- [ ] `.NET` domain model named `{Format}Document.cs`. `[DEFINED_ONLY]`
- [ ] `.NET` parser named `{Format}Parser.cs`. `[DEFINED_ONLY]`
- [ ] `.NET` writer named `{Format}Writer.cs`. `[DEFINED_ONLY]`
- [ ] No duplicate function definitions in the same format package. `[DEFINED_ONLY]`
- [ ] Sprint history identifiers (sprint/wave/train IDs) absent from production source comments. `[ADVISORY]`

## 6. Specification Traceability

- [ ] Every domain class carries `spec_qname: ClassVar[str]` matching the qname-registry entry. `[V111]`
- [ ] `spec_qname` value matches `shared/qname-registry/{format}.yaml` canonical entry. `[V43][REAL_FILE_TESTED]`
- [ ] New format additions are pre-registered in the qname architecture plan. `[V125]`
- [ ] Classes in `spec/` carry `architecture_only: true` and a stub marker. `[V48]`
- [ ] Non-ODF format domain classes cite spec concepts in file or class docstrings (`spec_concept:` tag). `[ADVISORY]`
- [ ] ODF format-prefixed class names (FodsCell, FodtParagraph) appear ONLY in `Compat/`. `[V45][REAL_FILE_TESTED]`
- [ ] `.NET` `Spec/*.cs` files carry `SpecQName` constant matching registry. `[ADVISORY]`
- [ ] All exported classes have a `spec_qname` or a documented exemption. `[ADVISORY]`

## 7. Public API Boundaries (Python)

- [ ] `__init__.py` declares explicit `__all__`. `[V65]`
- [ ] `__all__` excludes typing imports, module objects, and `_private` symbols. `[DEFINED_ONLY]`
- [ ] No function is exported that is only called from tests. `[ADVISORY]`
- [ ] Moving a function between submodules does not break the public API surface. `[DEFINED_ONLY]`
- [ ] `py.typed` marker file is present at the package root. `[UNVALIDATED]`

## 8. Error Handling

- [ ] Every Python package has `exceptions.py` with a format-specific exception hierarchy. `[V76][ADVISORY]`
- [ ] Exception base class inherits from `FormatFactoryError`. `[DEFINED_ONLY]`
- [ ] Parse exceptions carry offending offset or line number. `[DEFINED_ONLY]`
- [ ] `FileNotFoundError` is NOT caught and re-raised as a domain exception. `[DEFINED_ONLY]`
- [ ] .NET exceptions live in `Exceptions/{Format}Exception.cs`. `[DEFINED_ONLY]`

## 9. Test and Fixture Requirements

- [ ] At least 65 tests per format (L0 ≥5, L1 ≥20, L2 ≥30, L3 ≥10). `[DEFINED_ONLY]`
- [ ] Smoke tests (L0): package importable, `from_file()` works, exceptions defined. `[DEFINED_ONLY]`
- [ ] Unit tests (L1): parser returns correct domain model for valid input. `[DEFINED_ONLY]`
- [ ] Behavior tests (L2): writer roundtrip, analytics return correct values. `[DEFINED_ONLY]`
- [ ] Edge tests (L3): malformed inputs raise correct exceptions. `[DEFINED_ONLY]`
- [ ] At least 2 valid sample files at `samples/by-format/{format}/valid/`. `[DEFINED_ONLY]`
- [ ] At least 1 invalid/malformed sample at `samples/by-format/{format}/invalid/`. `[DEFINED_ONLY]`
- [ ] No test generates the ONLY sample file it tests (no synthetic-only fixtures). `[ADVISORY]`
- [ ] Test presence checked across parse/roundtrip/write tiers. `[UNVALIDATED]` (V190 planned)

## 10. Production Readiness

- [ ] No hardcoded local paths in library modules. `[DEFINED_ONLY]`
- [ ] No global mutable state in library modules. `[DEFINED_ONLY]`
- [ ] No debug, agent, or orchestration runtime dependencies in library modules. `[DEFINED_ONLY]`
- [ ] No script-style code (bare `if __name__ == "__main__"` logic) in library modules. `[DEFINED_ONLY]`
- [ ] All public Python functions have docstrings. `[ADVISORY]`
- [ ] No `TODO`/`FIXME`/`HACK` comments without a `GAP-*` or `TC-*` governed reference. `[ADVISORY]`
- [ ] No `raise NotImplementedError()` in non-abstract methods. `[DEFINED_ONLY]`
- [ ] Declared `changed_files` in sprint evidence all exist on disk. `[UNVALIDATED]` (V192 planned)
- [ ] Files with `remediation_deadline` in baseline have `remediation_status` tracked. `[UNVALIDATED]` (V193 planned)
- [ ] Stale installed packages do not shadow editable installs in `.venv/`. `[V137]`
