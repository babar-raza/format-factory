# Proof Authority Policy
# Format Factory — Governance Document
# Version: 1.0
# Date: 2026-06-05

## Decision: Option B — Ledger-Backed Proof Graph Projection

The Format Factory project uses Option B for proof authority:

### Definition

**Canonical operational record**: `reports/r90/product-code-change-ledger.json`
- Every source-changing work item must have an entry
- 129 entries as of 2026-06-05 (R90-R123)

**Required proof graph projection**:
- A deterministic proof graph projection MUST be generated from the ledger
- Generated by: `python tools/supervisor/project_product_ledger_to_proof_graph.py`
- Output: `reports/autonomous-system-audit/projected-proof-graph/nodes.jsonl`
- Output: `reports/autonomous-system-audit/projected-proof-graph/edges.jsonl`
- Output: `reports/autonomous-system-audit/projected-proof-graph/projection-report.json`

### "Ledger Only" Not Accepted

A POC proof claim based only on `product-code-change-ledger.json` WITHOUT a proof
graph projection is NOT accepted by the proof-backed POC gate.

The gate (proof_backed_poc_gate.py) enforces:
- `ledger_matches > 0 AND projection_found` → PASS
- `ledger_matches > 0 AND NOT projection_found` → FAIL with guidance to run projection
- `poc-targets.yaml alone` → FAIL (advisory only)

### Why Option B (Not Option A)

The project has relied on the product code change ledger as its primary operational
record since R86. Building a separate proof graph from scratch would require significant
backfill work. Option B allows the existing ledger to serve as the canonical record
while adding a deterministic projection that satisfies the proof graph requirement.

### Regeneration

The projection is regenerated whenever:
1. The ledger is updated (new sprint adds entries)
2. A new POC audit is run
3. The projection tool is updated

To regenerate:
```
python tools/supervisor/project_product_ledger_to_proof_graph.py
```

### No "Proof Graph Not Separately Maintained" Language

After this policy is applied, no report may say:
> "proof_graph: Not separately maintained — ledger is canonical"

Instead it must say:
> "proof_graph: Generated projection at reports/autonomous-system-audit/projected-proof-graph/ from ledger (129 entries)"
