## 2. Plan Binding

When a plan is active:
1. Read `.local/supervisor/active-plan-lock.json` — identifies active plan path and status
2. If plan lock is `IN_PROGRESS`, execute ONLY that plan's taskcards
3. Update `active-plan-lock.json` `last_taskcard` after each taskcard completes
4. When all taskcards done: write `status: COMPLETE` to the lock file
5. Do NOT read `reports/supervisor/next-sprint.md` while a plan is active

**BLOCKED:** Writing a plan lock requires running `tools/supervisor/write_plan_lock.py` as a registered skill
(RC-016). This capability is BLOCKED for Codex until skill dispatch is available.
**Interim:** Codex can read the active plan lock and follow it; writing requires intervention.

## 6. Continuation

After each sprint closeout:
1. Read `.local/supervisor/continuation-signal.json`
2. Verify `session_id` matches current agent session (cross-chat isolation)
3. If verdict is `CONTINUE`: read `reports/supervisor/next-sprint.md` for next tasks
4. If verdict is `STOP`:
   - `POST_PLAN_TERMINAL`: plan completed — stop and report
   - `SESSION_MISMATCH`: signal belongs to another session — do not consume
   - `MAX_ITERATIONS`: NOT a real stop — reset iteration to 0 and continue

## 7. Hard Stops
