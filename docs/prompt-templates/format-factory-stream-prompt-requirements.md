# Format Factory Stream Prompt Requirements

**Added:** 2026-06-04
**Authority:** local-memory-sync sprint 2026-06-04

## Purpose

Every stream prompt generated by the supervisor or written manually MUST include the following fields. This document defines required and stream-specific fields.

---

## Required Fields (ALL Streams)

| Field | Description |
|---|---|
| Sprint ID | Unique sprint identifier with stream and iteration |
| Stream | One of: Mainstream, Acceleration, Skills, Supervisor |
| Date | ISO date |
| Taskcards | List of work items with id, title, owner, status |
| Allowed paths | Exact list of files/dirs this sprint may write |
| Forbidden paths | Explicit list including src/net/*, src/python/* if not Mainstream |
| Lane ownership | Which lane owns which file/dir |
| File ownership map | Per-file lane assignment to prevent overlap |
| Overlap check | Explicit statement that no two lanes own the same file |
| taskcard-state.json path | Where to write the taskcard state file |
| Raw logs | Required: test run logs, package install logs |
| Evidence declaration | Path: .local/evidences/<run_id>/evidence-declaration.yaml |
| Evidence manifest | Path: .local/evidences/<run_id>/evidence-manifest.yaml |
| Review package ZIP | Path: .local/supervisor/reviews/<run_id>/declaration-review-package.zip |
| Absolute package path | Full path starting with C:\Users\prora\... |
| SHA-256 | Review package SHA-256 hash |
| Final git status | Output of git status at closeout |
| No-push statement | Explicit: no push, no commit, no publication unless authorized |

## Mainstream Prompts (additional required fields)

| Field | Description |
|---|---|
| Product-output floors | Minimum new capabilities per product track |
| POC dashboard | Current state of poc-targets.yaml |
| PASS quota | Minimum capability count for PASS verdict |
| Iteration loop | Which iteration, max iterations, continuation conditions |
| Continuation decision | POC_READY_CANDIDATE / CONTINUE / STOP signals |
| Ruflo mode | Current Ruflo mode (ABSENT/AUDIT_ONLY/etc.) |
| Ruflo fallback | Local coordinator if Ruflo absent |
| Machinery auto-adoption | Policy for consuming AI/skill handoffs |
| Acceleration feedback loop | What to report back to Acceleration after iteration |

## Acceleration Prompts (additional required fields)

| Field | Description |
|---|---|
| Sub-lane | A (governance harness), B (AI product acceleration), or both |
| AI cognitive layer | Which AI tools are active (live/fixture/skipped) |
| Live/fixture/skipped mode | Must be declared at sprint start |
| AI draft authority | All AI outputs labeled ai_draft |
| External tool intake | Which external tools Acceleration may call |
| GhidraMCP gate | DISABLED_BY_DEFAULT unless gate cleared |
| Mainstream-consumable packet | What handoff Acceleration will produce for Mainstream |
| Product-first justification | Which product blocker removed or throughput improved |

## Skills Prompts (additional required fields)

| Field | Description |
|---|---|
| Facilitation-first governance | Skills exist to make Mainstream faster, not for proof in isolation |
| Superpowers intake | Whether any Superpowers skill is being normalized this sprint |
| Local skill normalization | 5-step normalization checklist (if normalizing a skill) |
| Source-change authorization | What level of source change the skill is authorized to make |
| Receiver fixtures | Standardized handoff format for Mainstream consumption |
| Mainstream consumption packet | What Skills delivers for Mainstream to consume |

## Supervisor Prompts (additional required fields)

| Field | Description |
|---|---|
| Deterministic authority | Supervisor is deterministic traffic controller, not AI voter |
| AI advisory layer | If AI advisory is active, label its outputs advisory_draft |
| Ruflo runtime governance | Current Ruflo mode and approval state |
| External tool mode detection | Ruflo/Superpowers/GhidraMCP current modes |
| False pass/false stop | What supervisor detected and how it was handled |
| Product velocity scoring | Mainstream product output per sprint metric |
| Continuation signal | Deterministic signal: POC_READY_CANDIDATE / CONTINUE / STOP |
| Stream health | Per-stream health status |

## Anti-Skip Requirements

Every prompt must make it hard to skip required fields by:
1. Listing required fields explicitly
2. Using placeholder tokens ({{FIELD_NAME}}) for values to be filled in
3. Including a pre-closeout checklist that verifies all required fields are present

## Evidence Completeness Checklist (required in every prompt)

Before declaring sprint complete:
- [ ] taskcard-state.json written with all final statuses
- [ ] evidence-declaration.yaml written
- [ ] evidence-manifest.yaml written
- [ ] Review package ZIP built
- [ ] Review package SHA-256 computed and reported
- [ ] Absolute path to review package reported
- [ ] git status captured and written to final-git-status.txt
- [ ] No-push/no-commit/no-publication statement included in final response
- [ ] Raw test logs captured
- [ ] Changed files list written
