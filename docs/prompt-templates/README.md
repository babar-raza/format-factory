## Common Template Requirements

Every template includes:
- Role definition
- Sprint identity fields
- Stream boundary
- Product-first purpose statement
- Hard PASS quota
- Hard prohibitions
- Mandatory preflight
- Execution waves
- Evidence closeout
- Allowed verdicts
- Final response contract
- Prohibitions: no broad staging/reset/stash/clean; no push/publication/gate approval unless explicitly authorized
- Machinery must state how it helps POC
