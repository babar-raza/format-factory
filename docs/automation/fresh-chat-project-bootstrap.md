## Current Commercial Product Direction

The .NET commercial product (`src/net/{format}/`) is NOT a thin parser.

**The target is:**
- Load supported format into in-memory document object model (DOM)
- Inspect and manipulate format-specific entities
- Edit entities (cells, paragraphs, styles, lists, tables)
- Save back to same format with or without edits
- Export/convert to PDF, PNG, HTML, and related formats (later phases)

**Commercial readiness requires C7+ capability** (see `docs/commercial-product-capability-model.md`).

**Current .NET capability:** C4-C6-vertical-slice (load/save/edit DOM, basic entities only).
FODS: 42/42 PASS. FODT: 43/43 PASS.
`commercial_product_ready: false`. Gate 11: NOT APPROVED.
