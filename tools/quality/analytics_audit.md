# Analytics Audit — Synthetic Function Inventory

Generated by depth-quality-improvement plan, Phase 3.

## Problem

`compression_metrics.py` (651 LOC, 54 functions) and `json_stream.py` (926 LOC, 67 functions)
contain synthetic micro-predicates that inflate the API surface without spec backing.

## ZST compression_metrics.py — Function Classification

### Keep (10 functions — spec-derived or foundational)
- `zst_compressed_size` — foundational file-size check
- `zst_is_valid_file` — spec-derived magic number check (RFC 8878)
- `zst_decompressed_size` — foundational
- `zst_frame_count` — spec-derived (RFC 8878 frame structure)
- `zst_frame_sizes` — spec-derived
- `zst_file_info` — foundational aggregate
- `zst_compression_ratio` — fundamental metric
- `zst_is_single_frame` — spec-derived
- `zst_max_frame_size` — spec-derived
- `zst_frame_header_descriptor` — spec-derived (RFC 8878 section 3.1.1)

### Deprecate (44 functions — synthetic padding)
Arbitrary threshold checks:
- `zst_is_small_file`, `zst_is_large_file`, `zst_is_minimal_frame`
- `zst_is_smaller_than_1kb`, `zst_size_exceeds_100k`, `zst_size_exceeds_1k`

Simple arithmetic wrappers:
- `zst_total_frame_size`, `zst_min_frame_size`, `zst_frame_size_variance`
- `zst_largest_frame_ratio`, `zst_smallest_frame_ratio`, `zst_frame_count_is_one`
- `zst_decompressed_to_compressed_ratio`, `zst_frame_median_size`
- `zst_frame_size_range`, `zst_is_multi_frame`, `zst_frame_count_ratio`

Dubious metrics:
- `zst_avg_byte_value`, `zst_content_entropy`, `zst_byte_ratio`
- `zst_density`, `zst_overhead_bytes`, `zst_avg_compression_per_byte`

Duplicates:
- `zst_magic_valid` (duplicate of `zst_is_valid_file`)
- `zst_has_multiple_frames` (duplicate of `not zst_is_single_frame`)
- `zst_compressed_ratio` (duplicate of `zst_compression_ratio`)
- `zst_file_size_bytes` (duplicate of `zst_compressed_size`)
- `zst_compression_savings_ratio` (duplicate of `zst_savings_ratio`)

## NDJSON json_stream.py — Function Classification

### Keep (~15 functions)
- `ndjson_record_count` — foundational
- `ndjson_field_exists` — foundational
- `ndjson_unique_field_names` — foundational
- `ndjson_is_empty` — foundational
- `ndjson_max_field_count`, `ndjson_min_field_count` — useful
- `ndjson_total_field_count` — useful
- `ndjson_has_nested_objects` — spec-relevant
- `ndjson_max_nesting_depth` — spec-relevant
- `ndjson_is_homogeneous` — useful
- `ndjson_field_type_distribution` — useful
- `ndjson_schema_consistency` — useful
- `ndjson_all_records_are_dicts` — useful
- `ndjson_average_field_count` — useful
- `ndjson_average_record_size` — useful

### Deprecate (~52 functions)
- All `_density` functions, all `_count_minus_*` functions
- All simple boolean wrappers (`has_*_fields`, `has_*`)
- All `_value_count` functions (trivial aggregates)
- `ndjson_file_size_bytes` (just os.path.getsize)
