# FODG Examples — Flat OpenDocument Graphics

**Status:** ALPHA FOSS PREVIEW — NOT FOR COMMERCIAL USE
**Package:** aspose-format-factory-fodg
**capability_level:** alpha-foss-preview
**commercial_product_ready:** false

## What This Does

Demonstrates the `fodg` Python FOSS codec: load a .fodg file,
count pages and shapes, and extract text content.

## Requirements

- Python 3.9+
- No external dependencies (stdlib only)
- No network access required

## Sample Files

Uses `samples/by-format/fodg/` from the repository root.

## Run

```bash
cd <repo-root>
PYTHONPATH=src/python python examples/python/fodg/inspect_drawing_shapes.py
```

## Expected Output

```
FODG FOSS Example — alpha-foss-preview
File: minimal-drawing.fodg
  Pages: 1
  Shapes: N
  Text: [...]
```
