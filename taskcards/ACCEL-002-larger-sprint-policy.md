# ACCEL-002: Larger Sprint Policy

**Status:** completed (policy created)
**Sprint:** FODT-GATE10-REVIEW-PACKET-AND-NEXT-LANE-ACCELERATION-001

## Description
Establish sprint-sizing policy to reduce micro-sprint overhead. Define when metadata
notes are classified vs. repaired, and which sprint templates to use.

## Deliverable
- reports/acceleration/controlled-parallel-lanes-20260511.md (Sections 2, 5, 7)

## Key Policies
- IV may include narrow non-behavior repair
- Gate packet may include next-lane planning
- Source execution includes source + tests + state + evidence in one sprint
- Metadata notes classified (not repaired) unless final validation fails
- Expected cadence: 2-3 sprints per gate (down from 6-7)

## Sprint Templates
- Template A: Source + Tests + State + Evidence (1 sprint)
- Template B: IV + Narrow Repair + Proof (1 sprint)
- Template C: Gate Packet + Next-Lane Planning (1 sprint)
- Template D: Multi-Gate Verification (1 sprint)
