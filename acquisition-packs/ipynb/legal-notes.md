## Notes
The Jupyter Notebook format (nbformat) is defined by the open-source Jupyter Project under BSD 3-Clause license. The format is a well-documented JSON schema with no proprietary extensions or patent encumbrances. Multiple independent implementations exist across ecosystems (VS Code, JupyterLab, Google Colab, nteract). Safe for parser implementation.
