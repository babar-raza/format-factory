## TC-F4: Rollback and Recovery Plan

| Scenario | Command | Risk |
|---|---|---|
| Revert single modified file | `git checkout -- <file>` | LOW — only affects that file |
| Revert all modified files | `git checkout -- .` | HIGH — loses all 78 modified files |
| Remove untracked files | `git clean -fd` | CRITICAL — destroys 375 untracked files permanently |
| Stash all changes | `git stash --include-untracked` | MEDIUM — preserves work but clears working dir |
| Selective stash | `git stash push -m "name" -- <files>` | LOW — targeted preservation |

**WARNING:** Untracked files (375 total) are NOT protected by git. A `git clean -fd` or `git reset --hard` will permanently destroy them. These include:
- 2 new Python modules (src/python/ndjson/, src/python/toml/)
- 150+ new test files
- 10+ new supervisor tools
- 40+ governance taskcards
- All report/evidence directories

**Recommended safety measure:** Run `git stash --include-untracked -m "pre-checkpoint-backup"` before any destructive operation. This preserves all work in git reflog even if working directory is cleaned.
