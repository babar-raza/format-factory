# Raw Test Log Packaging Requirement

## Policy (R98+)
Product source changes require raw test logs for ACCEPTED_VERIFIED grade.

## Required
1. Evidence declaration supports `raw_log_paths` per work item
2. Materializer includes raw logs in review package
3. Declaration review package includes raw-test-logs/
4. Work-item grade links to raw logs
5. Without raw logs: maximum grade is ACCEPTED_WITH_LIMITATIONS
