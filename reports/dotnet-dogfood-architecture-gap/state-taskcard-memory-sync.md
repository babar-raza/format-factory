## Export Target Support Policy (5-Condition Rule)

Established by Lane H decision package. A .NET dogfood gap for format conversion (e.g., fods_to_csv_dotnet) can only be marked ACTIONABLE when ALL five conditions hold:

1. Source format library exists in `src/net/{source_format}/` and is functional
2. Target format writer library exists in `src/net/{target_format}/` (standalone, not embedded)
3. The target library exposes a public API consumable by the source format's exporter
4. The exporter class in the source library is wired to consume the target library
5. At least one dogfood test exists that exercises the end-to-end pipeline via the installed package
