# Manifest Consistency Repair Report
# Sprint: FORMAT-FACTORY-GOVERNANCE-REPEATABILITY-LAYER-HARDENING-PILOTS-001
# Date: 2026-06-08

## Problem Statement

The governance sprint (governance-repeatability-contracts-001) exhibited a 3-way count mismatch:
- `evidence-manifest.yaml` artifacts: **17**
- `materialized-evidence-manifest.yaml` artifacts_verified: **32**
- `changed_files` count in declaration: **33** (includes 1 duplicate)

## Root Cause Analysis

### Source 1: evidence-manifest.yaml (17 entries)
Generated by `build_declaration_review_package.py` from the `evidence_artifacts` array
in `evidence-declaration.yaml`. Only counts explicitly declared governance artifacts.

### Source 2: materialized-evidence-manifest.yaml (32 entries)
Generated by the materializer from ALL files the materializer could access including:
- `changed_files` in the declaration (32 of 33 unique after dedup)
- `evidence_artifacts` (overlaps with changed_files)
- Supervisor-generated artifacts

The materializer resolves all declared paths on the filesystem and includes both
evidence_artifacts and changed_files in its count.

### Source 3: changed_files count (33)
The declaration's `changed_files` list contains 33 entries but **includes a duplicate**:
`docs/governance/idempotency-contract.md` appears twice (lines 151 and 152).
After deduplication: 32 unique changed files.

## Why These Counts Are All Correct (Not a Bug)

| Count | Meaning | Expected Value |
|---|---|---|
| 17 | Explicitly declared evidence artifacts (governance docs, schemas, sidecars) | Correct for governance sprint |
| 32 | All unique files materializer verified on filesystem | Correct (= 33 - 1 duplicate) |
| 33 | Raw changed_files list (includes duplicate) | Contains 1 inadvertent duplicate |

## Action: Fix the Duplicate in changed_files

The evidence-declaration.yaml for the governance sprint has `docs/governance/idempotency-contract.md`
listed twice in `changed_files` (lines 151-152). This should be deduplicated.

**The 17 vs 32 discrepancy is NOT a bug** — they measure different things:
- evidence_artifacts (17) = curated list of deliverable artifacts
- materialized count (32) = all files touched including scaffolding

## Recommendation for Future Sprints

1. Include a note in evidence-declaration.yaml: `changed_files_count_note: "count includes all modified files, not just evidence artifacts"`
2. Add deduplication in the declaration generator to prevent duplicate entries
3. Document in CLAUDE.md that evidence_artifacts ≠ changed_files counts
