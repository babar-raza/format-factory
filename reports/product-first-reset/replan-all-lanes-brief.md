## Strategic Context

The project has accumulated significant machinery (supervisor, acceleration, skills) that is not consistently driving product output. The product-first POC reset (master-plan Section 43) requires all four lanes to replan from product-first goals.

3 commercial .NET products (FODS, FODT, Netpbm) + 3 reduced/FOSS products (ZST, Python Netpbm, SYLK/DIF) with real capability.

## Cross-Lane Dependencies

1. Mainstream needs Skills for governed product changes.
2. Mainstream needs Acceleration-B for AI-assisted code generation.
3. Skills needs Supervisor for continuation decisions.
4. Acceleration-A needs Supervisor for false verdict data.
5. No lane may block Mainstream unless removing a product blocker.

## Replan Rules

1. Mainstream gets priority in every sprint cycle.
2. Machinery lanes may run in parallel but must justify product impact.
3. If a machinery lane cannot justify product impact for 2 consecutive sprints, it pauses.
4. Cross-stream dependencies must be declared at sprint start, not discovered at closeout.
