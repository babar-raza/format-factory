# Skills Replan Brief

**Date:** 2026-06-03
**Lane:** Skills / Governed Execution
**Latest reviewed:** R112

## Current State

R112 was a strong Skills milestone: near-live v3 handoff proof, stream-local isolation, record-lane-execution promoted, 309 tests. Skills infrastructure is solid.

## Problem

Skills are well-defined but Mainstream consumption is inconsistent. Some skills exist but are not used in product sprints. The gap between "skill exists" and "Mainstream uses skill to produce product output" needs closing.

## Replan Goals

### R113+ Priorities
1. **Full live cycle execution:** Run at least 1 skill end-to-end in a real Mainstream sprint (not just proof-of-concept).
2. **Stream convergence:** Ensure skill definitions match what Mainstream actually needs for its 6 product tracks.
3. **Cross-stream dependency resolution:** Define handoff contracts between Skills and Mainstream.
4. **MCP readiness:** Prepare check-mcp-status and related skills for potential activation.

### Hard PASS Quota
- Minimum 2 skills consumed by Mainstream in a real product sprint.
- At least 1 new skill or skill improvement that addresses a Mainstream workflow gap.

### Success Criteria
- Mainstream sprint uses governed skills for product source changes.
- Skill execution transcripts exist for real product changes.
- Skill registry is current and matches actual Mainstream needs.

## Dependencies

- Needs Mainstream feedback on which workflows are manual/error-prone.
- Needs Supervisor for continuation decisions in multi-skill execution.
- Provides governed execution to Mainstream.
