# R109 Fresh Mainstream Gaps

## Remaining Depth Gaps (R110+)

### FODS .NET
- Formula cell support (read/write formulas)
- Sheet-level metadata (custom properties, protection status)
- Data validation (cell value constraints)
- Conditional formatting reading

### FODT .NET
- Table support (read/create tables within document)
- Style-aware paragraph creation (apply named styles)
- Metadata extraction (author, creation date, revision count)
- Image/embedded object support

### Netpbm .NET
- Resize with interpolation (bilinear/nearest-neighbor)
- Color space conversion (RGB<->HSV)
- Filter operations (blur, sharpen, median)
- Dithering algorithms

### Python/FOSS
- DIF structured export (write DIF files)
- SYLK formula cell support
- PGM histogram equalization
- Cross-format conversion tests

## R110 Recommended Focus
- Depth: formula cells (FODS), table support (FODT), resize with interpolation (Netpbm)
- FOSS: DIF write, PGM equalization
- Integration: cross-format conversion pipeline tests
