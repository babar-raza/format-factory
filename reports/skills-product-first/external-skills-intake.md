**Install required:** YES (workspace mutation)

Superpowers Core provides TDD, debugging, and planning patterns through 20+ skills and
3 slash commands (/brainstorm, /write-plan, /execute-plan). The brainstorm/plan/execute
pattern is useful for sprint planning. The TDD workflow patterns align with Format Factory's
test-first product approach.

### Useful Patterns
- brainstorm: structured ideation for sprint planning
- write-plan: systematic plan generation with acceptance criteria
- execute-plan: step-by-step execution with continuation logic

### Install Required
YES — plugin installs into .claude/ workspace. Creates .claude-plugin/ directory.

### Risks
1. **SessionStart injection (HIGH):** Superpowers Core injects context before every session
   via SessionStart. This conflicts with AGENTS.md which is the Format Factory session authority.
2. **Slash command collision (MEDIUM):** /brainstorm, /write-plan, /execute-plan may conflict
   with existing Format Factory command names.
3. **Context pollution (HIGH):** 20+ skills installed globally; unreviewed skills may influence
   agent behavior in unintended ways.

### Local Equivalent Exists
NO — but Format Factory sprint planning uses equivalent patterns via native tools.

### Recommended Status
EVALUATE_PATTERNS_ONLY — Extract brainstorm/plan/execute patterns as local reference templates.
DO NOT install. SessionStart injection incompatible with governed session model.
