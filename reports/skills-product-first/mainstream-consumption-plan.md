## Consumption Flow

### Step 1: Read the Consumption Packet
Mainstream reads `reports/skills-product-first/mainstream-consumption-packet.json`.
Extracts: selected_product_gap, recommended_skill, generated_handoff_path, allowed_files,
forbidden_files, acceptance_criteria.

### Step 2: Locate the Governing Template
Use recommended_skill to find the template in `docs/prompt-templates/skills/`.
Example: skill=add-dotnet-api → `add-dotnet-api-handoff-template.md`.

### Step 3: Validate the Enforcement Tier
Check the enforcement tier for the planned work:
- TIER 1 (FAIL_CLOSED): Mainstream is authorized. Skills contract required.
- TIER 2 (FAIL_WITH_REWORK): Mainstream is authorized. Test files needed.
- TIER 3 (YES_WITH_LIMITATIONS): Skills/Governance scope (reports/docs). Proceed with limitations.
- TIER 5 (BLOCKED_EXTERNAL_GATE): Push/Gate 8/11. Stop and record blocker.

### Step 4: Execute from the Handoff
Follow the handoff YAML (generated-handoffs/handoff-*.yaml) exactly:
- Only touch allowed_files listed in handoff
- Produce source diff, test files, transcript
- Run focused_test_command from handoff
- Capture test raw log

### Step 5: Produce Transcript
Create transcript JSON matching validate_skill_transcript.py schema.
Fields: invocation_id, skill_id, mode=live, inputs (handoff contents), allowed_files,
actual_files_changed (non-empty in live mode), tests_run, result, timestamp, ledger_entry_id.

### Step 6: Run Adoption Compliance
```python
from tools.supervisor.validate_adoption_compliance import validate_adoption
result = validate_adoption(declaration_work_item)
```
If compliant=False → fix missing fields → rerun. Do not stop.

### Step 7: Declare Evidence
Add work item to evidence-declaration.yaml:
- status: DONE
- evidence_paths: [transcript, source_diff, test_log, ledger_entry]
- test_refs: [test class + count]

## Supervisor Grading Integration

The Supervisor grades Mainstream work items against the 5-tier contract:

| Tier | Mainstream action | Grade if missing |
|------|------------------|-----------------|
| FAIL_CLOSED | Full source change + transcript + test log | REJECTED |
| FAIL_WITH_REWORK | Test files present | FAILED_NEEDS_REPAIR |
| YES_WITH_LIMITATIONS | Governance docs produced | ACCEPTED_WITH_LIMITATIONS |
| ACCEPT_WITH_LIMITATIONS | Planning docs present | ACCEPTED (advisory) |
| BLOCKED_EXTERNAL_GATE | Blocker recorded | BLOCKED_EXTERNAL |

The grading_rubric is in `reports/skills-product-first/handoff-to-supervisor.json`.
