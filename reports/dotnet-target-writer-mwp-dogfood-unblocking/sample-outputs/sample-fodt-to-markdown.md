# Introduction

This document demonstrates the FODT Markdown export via FormatFactory.Markdown.MarkdownWriter.

## Section 1

Each heading uses ATX-style markup (# through ######).

Paragraph text is written as-is.

### Subsection 1.1

Deeper heading levels are supported up to level 6.

## Conclusion

The MarkdownWriter is a standalone Format Factory library that can be reused by any exporter.
