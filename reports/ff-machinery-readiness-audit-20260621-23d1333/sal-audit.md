# SAL Audit — Specification Authority Layer
# Sprint ID: ff-machinery-readiness-audit-20260621-23d1333

## Summary

**The SAL is split into two disconnected, parallel pipelines. Neither is end-to-end functional.**
This is not a new finding — it is documented exhaustively in plans/strategic/snoopy-juggling-seal.md.
The SAL is the most critical infrastructure gap blocking QName-governed product deepening.

## Evidence (primary source: plans/strategic/snoopy-juggling-seal.md, version 3.0 2026-06-18)

### Pipeline A — Real Spec Cache (partially complete, consumer integration BROKEN)

| Format | Source | Sections | Verified Facts | End-to-end? |
|--------|--------|----------|---------------|-------------|
| FODS | ODF 1.3 Part 3 PDF | 884 | 78 | NO — facts not loaded into context packs |
| ZST | RFC 8878 + 9659 | 0 extracted | 0 | NO |
| FODT | ODF (shared source) | 0 normalized | 0 | NO |
| CSV | RFC 4180 | unknown | 0 | NO |
| Others (16 formats) | Various | unknown | 0 | NO |

**Critical gap:** 78 verified FODS facts (FACT-FODS-NNN format) exist in
`.local/spec-cache/fods/1.3/workbench/verified-facts-review.yaml` but are
NEVER emitted by `sal_master_runner.py` and are NOT loaded into context packs.

### Pipeline B — Template Fact Generator (complete but FAKE)

- `sal_master_runner.py` produces 128 hardcoded template facts for 22 formats
- It NEVER reads any specification file
- All 10 real SAL tools (extractor, normalizer, indexer, etc.) are bypassed
- Template facts use incompatible ID namespaces (`FODS-FACT-001`, `ODF-FACT-*`, `ZST-FACT-001`)
- These IDs CANNOT pass `validate_spec_fact_refs.py` which requires `FACT-<FORMAT>-NNN`
- `sal-facts-latest.json` is written to disk but has ZERO downstream readers

## Root Cause (from snoopy-juggling-seal.md)

1. `sal_master_runner.py` was written with hardcoded template facts as a placeholder
2. The real extraction pipeline was never connected to the master runner
3. The 78 verified FODS facts from workbench stage are stranded — no consumer reads them
4. The context_pack_builder.py can read real facts but was never called with the right inputs
