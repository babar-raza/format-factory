## Defect Analysis

### D103-01: evidence-manifest path mismatch
- **Location:** build_declaration_review_package.py:90-91
- **Root cause:** Builder looks for `.local/evidences/<run_id>/evidence-manifest.yaml`. R102 placed manifest at `reports/acceleration-r102/evidence-manifest.yaml`.
- **Fix:** Copy manifest to `.local/evidences/` OR update builder to also check declaration's `evidence_root` field.

### D103-02: Review package excludes acceleration evidence
- **Root cause:** Builder only packages supervisor pipeline outputs. No code path includes `evidence_artifacts` from the declaration.
- **Fix:** Add loop over `evidence_artifacts` and `evidence_paths` from declaration to include them in ZIP.

### D103-03: Stale selected-product-gaps.json
- **Root cause:** `.local/supervisor/selected-product-gaps.json` generated by select_poc_gaps.py during a product sprint. Not refreshed for acceleration.
- **Fix:** Regenerate gaps fresh at R103 start using select_poc_gaps.py.

### D103-04: 0 acceleration gaps in prompt
- **Root cause:** POC matrix (poc-targets.yaml) only has product gaps. Acceleration stream has no matrix entries.
- **Fix:** Generate acceleration-specific gaps from tool inventory and skill registry, not from POC matrix.

### D103-05: No co-located manifest
- **Fix:** Copy evidence-manifest.yaml to `.local/evidences/<run_id>/` alongside declaration.
