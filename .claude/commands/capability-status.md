# /capability-status

Read the compiled capability registry and parity report; print a summary of cross-agent parity status.

## What This Command Does

1. **Check registry exists** — If `.governance/capabilities/registry.yaml` is absent, print guidance and stop.
2. **Load registry** — Count capabilities by `parity_status` and `agent_surfaces`.
3. **Load parity report** — Read `overall_verdict` from `.governance/capabilities/parity-report.yaml`.
4. **Print summary table** — Capability counts per parity bucket.
5. **Print overall verdict** — PASS / WARN / FAIL from the parity report.

## When to Use

- Before any skill/command change, to confirm baseline parity
- After `/sync-capabilities`, to confirm the sync succeeded
- When diagnosing discoverability gaps between agents

## Steps

```
1. If .governance/capabilities/registry.yaml does not exist:
      Print: "Registry not found. Run /sync-capabilities first."
      STOP.
2. Load .governance/capabilities/registry.yaml
3. Count capabilities by parity_status:
      - FULL_PARITY: skill has command file + registry entry
      - PARTIAL: command file exists OR in registry, but not both
      - MISSING_COMMAND: command file absent
      - ORPHAN: command .md file with no skill entry
4. Count agent_surfaces.claude_code=true, codex=true, ci=true
5. If .governance/capabilities/parity-report.yaml exists:
      Load overall_verdict
   Else:
      overall_verdict = "UNKNOWN (run /sync-capabilities)"
6. Print:
      Total capabilities: N
      FULL_PARITY:       N
      PARTIAL:           N
      MISSING_COMMAND:   N
      ORPHAN:            N
      claude_code:       N discoverable
      codex:             N discoverable
      ci (routed):       N routed
      Overall verdict:   PASS | WARN | FAIL | UNKNOWN
```

## Source Files

- Registry: `.governance/capabilities/registry.yaml` (generated by `tools/capability_sync/inventory_capabilities.py`)
- Parity report: `.governance/capabilities/parity-report.yaml` (generated by `tools/capability_sync/validate_parity.py`)

## Fallback

If registry absent: run `/sync-capabilities` to generate it.

## Notes

This command is **read-only** — it never modifies any file.
