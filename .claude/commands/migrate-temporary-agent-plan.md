# /migrate-temporary-agent-plan

Extract durable content from a temporary `.claude/plans/` or `plans/.claude/` agent plan
and merge it into the appropriate permanent layer plan files in `plans/layers/`.

Temporary plans (generated by plan mode) should not persist as the sole authority for
layer decisions. Their durable content belongs in permanent layer files.

## Handoff Fields (required)

| Field | Description |
|---|---|
| `temporary_plan_path` | Path to the temporary plan file (e.g., plans/.claude/foo.md) |
| `target_layer_ids` | List of layer IDs that should receive durable content |

## Execution

1. Read the temporary plan file
2. Identify durable content: gap register entries, decision records, task definitions
3. For each target layer, open the permanent plan file and merge the durable content
4. Append durable decisions to `plans/layers/decision-register.yaml`
5. Mark the temporary plan's durable content as MIGRATED with a comment
6. Append change entries to `plans/layers/change-ledger.jsonl`

## Mandatory Validations

- `temporary_plan_exists`: source file must exist
- `no_product_source_changes`: this skill must not modify `src/python/` or `src/net/`
- `durable_content_migrated`: at least one permanent layer file must be updated
